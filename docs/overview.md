# Product overview

S-Class is a subscription-based eLearning review platform with structured
subjects, lessons, video/PDF content, problem sets, progress tracking, and a
book storefront.

The production student experience is the Landing website plus `/portal/*`.
Admin is a separate application. Portal remains a source/local workspace.

For the maintained documentation set, start with [docs/README.md](README.md).
See [Student features](student/features.md), [Admin features](admin/features.md),
and [Current architecture](architecture/current.md).
